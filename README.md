# RESUME-CLI


**基于配置的简历生成工具**

## 项目说明
为了学习 TypeScript 和 React 创建此项目。目前提供配置驱动的网页简历，构建后可作为静态页面使用。

## 快速入门
### 准备工作

安装 Node.js 22.22.2+、24.15+ 或 26+（推荐受支持的 LTS 版本），然后在仓库目录执行：

```bash
npm ci
```

### 使用

修改 `src/util/default.js` 中的个人资料、经历、项目和技能，启动本机预览：

```bash
npm start
```

开发服务器默认仅监听 `127.0.0.1`，访问终端显示的地址。

```bash
npm run build
```

生产页面与 JS/CSS 文件输出到 `public/`。每次构建会清理旧产物，请勿把源文件放入该目录。生成的是网页简历，项目当前没有独立的 PDF 导出命令。

运行构建、简历渲染与开发服务器回归：

```bash
npm test
```
